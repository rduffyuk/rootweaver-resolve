# Retained investigation implementation reference

These unchanged source modules expose the bounded hypothesis/check loop, evidence projection and packet capture/decoding contract used by the retained investigation. They are included for source review, not installed as a general cluster executor. The lab host adapters and private Observe deployment are not distributed. Source hashes are in source-manifest.json.

The runnable standalone application is the workbench and the optional fixed HTTP analysis route described in the root README. The workbench does not claim to launch a fresh packet investigation.
